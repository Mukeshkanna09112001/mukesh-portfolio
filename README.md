# Mukesh Kanna R — Portfolio

Next.js 14 (App Router) + React 18, plain CSS. No UI libraries.

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content
All text lives in `data/profile.js` (experience, projects, skills, education).
Replace `public/Mukesh_Kanna_R_Resume.pdf` to update the résumé download.

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. vercel.com → Add New Project → import the repo → Deploy (defaults work).
